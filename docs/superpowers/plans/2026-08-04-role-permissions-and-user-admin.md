# Role Permissions + Admin User CRUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the role→permission mapping out of sitesight-pro's hardcoded `usePermissions.ts` map into a backend-managed, admin-editable `RolePermission` table, surface each user's resolved permissions on their auth token, and redesign the admin "Users" page into a data-table with edit/role/permission/revoke row actions.

**Architecture:** A new `RolePermission` Prisma model + `PermissionsModule` (`GET /roles/permissions`, `PUT /roles/:role/permissions`, administrator-only) becomes the source of truth for what each role grants. `AuthService.issueTokens` resolves a user's permissions from their roles and threads them onto the access token and every `AuthResult`, exactly parallel to how `roles` already works. The frontend deletes its hardcoded map and reads `state.auth.permissions` instead. `AdminUsers.tsx` becomes a data-table (existing shadcn `Table` primitives, no new dependency) with row actions that call the existing role/status endpoints plus two new ones: an admin profile-edit endpoint and the new role-permission editor.

**Tech Stack:** NestJS, Prisma/PostgreSQL, class-validator, RTK Query, React, shadcn/ui (Table, Dialog, AlertDialog, DropdownMenu — all already present in this codebase).

## Global Constraints

- No automated tests in this pass — verify every task manually (compile check + a live request/click-through), consistent with every other plan executed against this backend to date.
- Permissions are per-*role*, not per-user — there is no per-user override table or resolution logic. (Spec §Scope decisions #1.)
- Backend authorization enforcement is unchanged — every existing `@Roles(...)` guard on every controller stays exactly as-is. Permissions are additive and UI-gating-only for now. (Spec §Scope decisions #2.)
- The permission catalog (the 13 fixed strings) is defined in code on both BE and FE, matching the existing `AppRole` convention — only *role→permission assignment* is dynamic/DB-editable, not the catalog itself. (Spec §Scope decisions #3.)
- Full spec: `docs/superpowers/specs/2026-08-04-role-permissions-and-user-admin-design.md`.
- This backend has other in-flight work (`app.module.ts` currently has two lines tagged `// TEMP (Task 3 standalone verification, removed in Task 5)` from an unrelated plan). Do not touch or remove those lines — only add to the `imports`/`providers` arrays around them.

- [ ] **Step 3: Write the service**

Create `src/permissions/permissions.service.ts`:

```ts
import { Injectable } from '@nestjs/common';
import { AppRole } from '@prisma/client';
import { AuditLogService } from '../audit-log/audit-log.service';
import { PrismaService } from '../prisma/prisma.service';
import { Permission } from './permission.constants';

@Injectable()
export class PermissionsService {
  constructor(
    private prisma: PrismaService,
    private auditLogService: AuditLogService,
  ) {}

  async getAllRolePermissions(): Promise<Record<AppRole, Permission[]>> {
    const rows = await this.prisma.rolePermission.findMany();
    const result = Object.fromEntries(
      Object.values(AppRole).map((role) => [role, [] as Permission[]]),
    ) as Record<AppRole, Permission[]>;

    for (const row of rows) {
      result[row.role].push(row.permission as Permission);
    }
    return result;
  }

  async resolvePermissionsForRoles(roles: AppRole[]): Promise<Permission[]> {
    if (roles.length === 0) {
      return [];
    }
    const rows = await this.prisma.rolePermission.findMany({
      where: { role: { in: roles } },
    });
    return [...new Set(rows.map((row) => row.permission))] as Permission[];
  }

  async replaceRolePermissions(
    role: AppRole,
    permissions: Permission[],
    adminUserId: string,
    ip?: string,
  ): Promise<Permission[]> {
    await this.prisma.$transaction([
      this.prisma.rolePermission.deleteMany({ where: { role } }),
      this.prisma.rolePermission.createMany({
        data: permissions.map((permission) => ({ role, permission })),
      }),
    ]);

    await this.auditLogService.log(
      adminUserId,
      'role_permissions.updated',
      'RolePermission',
      role,
      { role, permissions },
      ip,
    );

    return permissions;
  }
}
```

- [ ] **Step 4: Write the controller**

Create `src/permissions/permissions.controller.ts`:

```ts
import { Body, Controller, Get, Ip, Param, Put } from '@nestjs/common';
import { ApiBearerAuth, ApiOperation, ApiTags } from '@nestjs/swagger';
import { AppRole } from '@prisma/client';
import type { AuthenticatedUser } from '../auth/types/jwt-payload.type';
import { CurrentUser } from '../common/decorators/current-user.decorator';
import { Roles } from '../common/decorators/roles.decorator';
import { UpdateRolePermissionsDto } from './dto/update-role-permissions.dto';
import { PermissionsService } from './permissions.service';

@ApiTags('Permissions')
@ApiBearerAuth()
@Controller('roles')
export class PermissionsController {
  constructor(private permissionsService: PermissionsService) {}

  @ApiOperation({ summary: "Get every role's current permission set (administrator only)" })
  @Roles('administrator')
  @Get('permissions')
  getAll() {
    return this.permissionsService.getAllRolePermissions();
  }

  @ApiOperation({ summary: "Replace a role's permission set (administrator only)" })
  @Roles('administrator')
  @Put(':role/permissions')
  replace(
    @Param('role') role: AppRole,
    @Body() dto: UpdateRolePermissionsDto,
    @CurrentUser() admin: AuthenticatedUser,
    @Ip() ip: string,
  ) {
    return this.permissionsService.replaceRolePermissions(role, dto.permissions, admin.userId, ip);
  }
}
```

        tokenHash: this.hashToken(refreshToken),
        expiresAt: new Date(Date.now() + REFRESH_TOKEN_TTL_MS),

      sameSite: 'lax',
      path: '/auth',

export type ManagedUser = Omit<AuthUser, 'permissions'>;

export interface UpdateProfilePayload {
  name?: string;
  phone?: string;
  company?: string;
  certificationDetails?: string;
}

export interface UpdateUserStatusPayload {
  id: string;
  status: 'active' | 'inactive';
}

export interface UpdateUserRolesPayload {
  id: string;
  roles: AppRole[];
}

export const usersApi = baseApi.injectEndpoints({
  endpoints: (builder) => ({
    updateProfile: builder.mutation<ManagedUser, UpdateProfilePayload>({
      query: (body) => ({ url: '/users/me', method: 'PATCH', body }),
      onQueryStarted: async (_arg, { dispatch, queryFulfilled }) => {
        try {
          const { data } = await queryFulfilled;
          dispatch(profileUpdated(data));
        } catch {
          // Left to the calling component's own error state (useUpdateProfileMutation).
        }
      },
    }),
    // Administrator only.
    getUsers: builder.query<ManagedUser[], void>({
      query: () => '/users',
      providesTags: (result) => [
        ...(result ?? []).map((u) => ({ type: 'User' as const, id: u.id })),
        { type: 'User' as const, id: 'LIST' },
      ],
    }),
    updateUserStatus: builder.mutation<ManagedUser, UpdateUserStatusPayload>({
      query: ({ id, status }) => ({ url: `/users/${id}/status`, method: 'PATCH', body: { status } }),
      invalidatesTags: (_result, _error, { id }) => [{ type: 'User' as const, id }],
    }),
    updateUserRoles: builder.mutation<ManagedUser, UpdateUserRolesPayload>({
      query: ({ id, roles }) => ({ url: `/users/${id}/roles`, method: 'PATCH', body: { roles } }),
      invalidatesTags: (_result, _error, { id }) => [{ type: 'User' as const, id }],
    }),
  }),
});

export const {
  useUpdateProfileMutation,
  useGetUsersQuery,
  useUpdateUserStatusMutation,
  useUpdateUserRolesMutation,
} = usersApi;

  const openPermissionsDialog = (user: ManagedUser) => {
    setPermissionsTarget(user);
    if (user.roles.length === 1) {
      setPermissionsRole(user.roles[0]);
      setDraftPermissions(rolePermissionsMap?.[user.roles[0]] ?? []);
    } else {
      setPermissionsRole(null);
    }
  };

  const choosePermissionsRole = (role: AppRole) => {
    setPermissionsRole(role);
    setDraftPermissions(rolePermissionsMap?.[role] ?? []);
  };

  const togglePermission = (permission: Permission) => {
    setDraftPermissions((prev) =>
      prev.includes(permission) ? prev.filter((p) => p !== permission) : [...prev, permission]
    );
  };

  const handleSavePermissions = async () => {
    if (!permissionsRole) return;
    try {
      await updateRolePermissions({ role: permissionsRole, permissions: draftPermissions }).unwrap();
      toast({
        title: 'Permissions updated',
        description: `Every user with the ${permissionsRole} role is affected.`,
      });
      setPermissionsTarget(null);
      setPermissionsRole(null);
    } catch {
      toast({ title: 'Error', description: 'Failed to update permissions.', variant: 'destructive' });
    }
  };

  const closePermissionsDialog = () => {
    setPermissionsTarget(null);
    setPermissionsRole(null);
  };
